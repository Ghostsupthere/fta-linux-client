Compiled into the game executable (Wow64)
-----------------------------------------

The game is built from the repository above. Its ThirdParty/ folder holds the libraries the engine builds in
(for example zlib, bzip2, expat, FreeType, LZMA and PCRE), each with its own licence file. SDL3 is not shipped:
it is a system library that FTA-Linux/install-deps.sh asks for.

Compiled into the launcher (FTA-Linux/fta-launcher)
---------------------------------------------------

Slint (GPL-3.0-only option) and the Rust crates listed in licenses/THIRD-PARTY-CRATES.txt.
Fonts: Cinzel and Cinzel Decorative, SIL Open Font License 1.1 (licenses/OFL-Cinzel.txt, OFL-CinzelDecorative.txt).
